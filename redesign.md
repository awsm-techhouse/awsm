Always translate technical language into business language first.

Technical implementation:
REST API

> Sistem untuk menyimpan, mengelola, mencari, dan memperbarui data
> secara terpusat.

> Machine Learning Classification Model

Say:

> Sistem yang membantu mengelompokkan data secara otomatis berdasarkan
> pola yang ditemukan.
